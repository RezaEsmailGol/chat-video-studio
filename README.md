# Chat Video Studio 🎬

یک ابزار ساده و تک‌فایلی برای طراحی **گفت‌وگوهای نمایشی** و ساخت ویدیوی چت. قالب‌های فعال: **تلگرام، بله، ایتا، واتساپ و روبیکا**. طراحی هر قالب بر اساس ظاهر مرجع و اسکرین‌شات‌های ارائه‌شده انجام شده و بازسازی نمایشی است، نه رابط رسمی پیام‌رسان‌ها.

**همه کد برنامه در تنها فایل `index.html` قرار دارد.** نصب، Node.js، دیتابیس سرور و فرایند Build لازم نیست.

## استفاده

1. فایل `index.html` را باز کن؛ یا کل مخزن را Clone کن و فایل را با مرورگر اجرا کن.
2. یکی از پنج قالب تلگرام، بله، ایتا، واتساپ یا روبیکا را انتخاب کن. نام پیش‌فرض مخاطب **رضا اسماعیل گل** است و می‌توانی از بخش «نام مخاطب در ویدیو» یا تنظیمات پیشرفته آن را تغییر بدهی. پیام‌ها و رسانه‌های خودت را اضافه کن؛ تنظیمات هر پیام‌رسان در تب مخصوص آن نمایش داده می‌شود.
3. پیش‌نمایش بگیر و خروجی عکس یا ویدیو بساز.
4. پروژه در مرورگر به‌صورت خودکار در IndexedDB ذخیره می‌شود. برای پشتیبان‌گیری، از گزینه **دانلود پروژه JSON** استفاده کن و بعداً آن را وارد کن.

اگر بازکردن مستقیم HTML در مرورگرت محدودیت داشت، از پوشه پروژه این دستور اختیاری را اجرا کن:

```sh
python -m http.server 8000
```

و آدرس `http://localhost:8000` را باز کن.

## سناریوی پیش‌فرض و کد منبع

- در اولین بازدید، **گفت‌وگوی نمایشی ۱۰ پیامی معرفی Chat Video Studio** با نام مخاطب «رضا اسماعیل گل» در پیش‌نمایش باز می‌شود.
- دکمه **«بازگردانی سناریوی معرفی»** پیام‌های نمایشی را برمی‌گرداند؛ قبل از جایگزینی پیام‌های فعلی تأیید می‌گیرد.
- اگر قبلاً پروژه‌ای در IndexedDB ذخیره کرده‌اید، همان پروژه بازیابی می‌شود و سناریوی نمونه روی تغییرات شما نوشته نخواهد شد.
- پیوند **[مخزن اصلی GitHub](https://github.com/RezaEsmailGol/chat-video-studio)** در پایین محیط برنامه قرار دارد.

## به‌روزرسانی رابط کاربری

- چیدمان واکنش‌گرا برای موبایل و دسکتاپ، دکمه‌های اصلی واضح‌تر و راهنمای چهارمرحله‌ای.
- تغییر سریع نام و عکس مخاطب در بالای ویرایشگر.
- تنظیمات کم‌استفاده در بخش بازشونده «تنظیمات بیشتر».
- نمایش راهنمای اختصاصی هر قالب و امکان کپی لینک عمومی برنامه.
- تأیید قبل از حذف کل گفت‌وگو یا جایگزینی با پیام‌های نمونه.
- ذخیره دستی با `Ctrl+S` یا `Cmd+S` و ذخیره خودکار در مرورگر.
- پروژه‌های قدیمی با نام نمایشی پیش‌فرض قبلی به «رضا اسماعیل گل» تغییر می‌کنند؛ نام‌های سفارشی کاربران حفظ می‌شوند.

## نکات مهم

- برای فونت، ایموجی و کتابخانه‌های CDN فعلاً اینترنت لازم است.
- خروجی ویدیو بسته به پشتیبانی مرورگر **MP4 یا WebM** است؛ پسوند واقعی فایل مشخص می‌شود.
- فایل ویدیویی ضمیمه در چت فعلاً به‌شکل **تصویر بندانگشتی** دیده می‌شود و به‌صورت ویدیوی متحرک داخل خروجی قرار نمی‌گیرد.
- ذخیره خودکار مختص همین مرورگر است و یک پروژه فعال را نگه می‌دارد؛ برای بکاپ از JSON استفاده کن.
- آزمایش خودکار روی Chromium و Firefox انجام شده، اما برای مرورگرهای دیگر و گوشی‌های واقعی هنوز تست دستی لازم است.
- برای انتشار نهایی، Tailwind CDN آزمایشی باید با CSS مناسب Production جایگزین شود، بدون اینکه ساختار تک‌فایلی نرم‌افزار تغییر کند.

## گزارش تست مرورگر (۲۲ اکتبر ۲۰۲۶)

تست واقعی با Playwright روی کد شاخه توسعه انجام شده است:

- **Chromium:** پنج قالب از نظر پیش‌نمایش Canvas، تصویر PNG، خروجی و ورود پروژه JSON و **ساخت MP4 قابل پخش** تأیید شدند. ابعاد فایل‌ها ۷۵۰×۱۳۳۴ و مدت ویدیوهای آزمایشی حدود ۲٫۳۵ تا ۲٫۴ ثانیه بود.
- **Firefox:** هر پنج قالب در پیش‌نمایش Canvas تأیید شدند؛ یک خروجی **WebM معتبر** نیز برای روبیکا ساخته شد.
- **صدا:** مسیر خروجی WebM همراه با افکت صوتی بررسی شد و حضور ترک‌های ویدیو و **Opus audio** تأیید گردید (در Chromium).
- **WebKit در لینوکس:** پیش‌نمایش هر پنج قالب موفق بود؛ ضبط ویدیو در محیط headless آزمایشی با بسته‌شدن مرورگر همراه شد، بنابراین **خروجی Safari هنوز تأیید نشده است**.
- **موبایل:** در عرض ۳۹۰ پیکسل، پیش‌نمایش نمایش داده شد و اسکرول افقی ناخواسته مشاهده نشد.

[اجرای موفق تست پنج قالب و سازگاری مرورگرها](https://github.com/RezaEsmailGol/chat-video-studio/actions/runs/39731210969)

تست‌های مرورگری از فایل‌های موقت GitHub Actions اجرا شدند و برای ساده ماندن نسخه تک‌فایلی، در مخزن نهایی نگهداری نمی‌شوند.
